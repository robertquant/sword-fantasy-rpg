# 视觉与战斗系统优化路线图

## 第一阶段：视觉素材补到可用

当前问题：
- 主角、村长、怪物仍是静态图，且部分素材有白底。
- 主角没有四方向行走动画。
- 战斗里角色没有攻击/受击表现。
- 首页、地图、战斗背景已开始接入，但整体风格还不统一。

要做：
- 主角四方向行走精灵表。
- 主角攻击/受击简单动画。
- 村长透明 NPC 精灵。
- 竹叶蛇透明怪物精灵。
- 竹妖透明 Boss 精灵。
- 首页背景正式替换。
- 对话框、HUD、战斗按钮统一为东方玄幻 UI 风格。

## 第二阶段：重做战斗系统

当前问题：
- 战斗只有攻击、技能、敌人反击，敌人差异和策略性都很弱。

要升级成：
- 回合状态机：玩家选择 → 执行动画 → 敌人行动 → 结算状态。
- 敌人技能：
  - 竹叶蛇：普通攻击、毒牙；中毒 3 回合，每回合扣血。
  - 竹妖：竹刺攻击、竹影分身提升闪避、根须缠绕让玩家下回合伤害降低。
- 玩家技能：
  - 普通攻击。
  - 剑气斩：高伤害，消耗 MP。
  - 防御：减伤一回合。
  - 净息：解除中毒或回复少量 HP/MP，可后续解锁。
- 状态效果：
  - 中毒。
  - 防御。
  - 闪避提升。
  - 缠绕/虚弱。
- 战斗日志更清楚，例如：
  - “竹叶蛇使用毒牙，你中毒了。”
  - “中毒造成 5 点伤害。”
  - “竹妖进入竹影分身，闪避提升。”

## 第三阶段：战斗表现优化

目标：让打斗看起来更像游戏。

要做：
- 攻击时角色前冲/抖动。
- 受击时闪白或震动。
- 技能释放有剑气特效。
- 中毒有绿色粒子或状态图标。
- 敌人血条、玩家血条更明显。
- 战斗胜利弹窗显示：
  - 经验。
  - 金币。
  - 任务进度。
  - 是否升级。

## 第四阶段：内容节奏优化

当前问题：
- 任务链较直，需要更清晰的剧情节奏和阶段反馈。

要做：
- 第一个任务：击败 3 条竹叶蛇。
- 回村长复命，获得奖励和剧情。
- 第二个任务：进入竹林深处击败竹妖。
- 竹妖战前加一句剧情提示。
- 竹妖战后给明确结算：“青云村篇章完成”。
- 后续预留入口：幽竹林深处 / 赤焰山。
